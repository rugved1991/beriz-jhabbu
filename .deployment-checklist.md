# Deployment Checklist

Use this checklist when deploying Beriz Jhabbu to production.

## Pre-Deployment

- [ ] All tests pass locally
  - [ ] Frontend: `npm test -- --no-watch --watchAll=false`
  - [ ] Backend: `cd server && npm test -- --no-watch --watchAll=false`
- [ ] Frontend builds successfully: `npm run build`
- [ ] Backend builds successfully: `npm run server:build`
- [ ] Code committed and pushed to GitHub
- [ ] Environment variables documented

## Backend Deployment (Render)

- [ ] Create Render account
- [ ] Create new Web Service
- [ ] Connect GitHub repository
- [ ] Configure service:
  - [ ] Root Directory: `server`
  - [ ] Build Command: `npm install && npm run build`
  - [ ] Start Command: `npm start`
- [ ] Set environment variables:
  - [ ] `NODE_ENV=production`
  - [ ] `PORT=3001`
  - [ ] `CLIENT_URL=<your-vercel-url>` (update after frontend deployment)
- [ ] Deploy and wait for completion
- [ ] Note backend URL: `https://______.onrender.com`
- [ ] Test health endpoint: `https://______.onrender.com/health`

## Frontend Deployment (Vercel)

- [ ] Create Vercel account
- [ ] Import GitHub repository
- [ ] Configure project:
  - [ ] Framework: Create React App
  - [ ] Build Command: `npm run build`
  - [ ] Output Directory: `build`
- [ ] Set environment variables:
  - [ ] `REACT_APP_SERVER_URL=<your-render-url>`
- [ ] Deploy and wait for completion
- [ ] Note frontend URL: `https://______.vercel.app`

## Post-Deployment

- [ ] Update backend `CLIENT_URL` with actual Vercel URL
- [ ] Wait for Render to redeploy with new CORS settings
- [ ] Test frontend loads correctly
- [ ] Test WebSocket connection (check browser DevTools)
- [ ] Test room creation
- [ ] Test multiplayer (two browsers/devices)
- [ ] Test bot functionality
- [ ] Test reconnection
- [ ] Monitor logs for errors

## Verification Tests

### Backend Health Check
```bash
curl https://your-backend.onrender.com/health
```
Expected: `{"status":"ok","rooms":0,...}`

### Frontend Access
- [ ] Visit frontend URL
- [ ] No console errors
- [ ] WebSocket connection established

### Multiplayer Test
- [ ] Browser 1: Create room
- [ ] Browser 2: Join room with code
- [ ] Both players visible in lobby
- [ ] Start game works
- [ ] Card plays synchronize

### Bot Test
- [ ] Create room
- [ ] Add bot player
- [ ] Start game
- [ ] Bot plays automatically

## Monitoring Setup

- [ ] Bookmark health check URL
- [ ] Set up uptime monitoring (optional)
- [ ] Configure log monitoring (optional)
- [ ] Document support contacts

## Rollback Plan

If deployment fails:
- [ ] Render: Click "Rollback" in dashboard
- [ ] Vercel: Select previous deployment and promote
- [ ] Verify rollback successful
- [ ] Investigate and fix issues
- [ ] Redeploy

## Environment Variables Reference

### Backend (Render)
```
NODE_ENV=production
PORT=3001
CLIENT_URL=https://your-app.vercel.app
```

### Frontend (Vercel)
```
REACT_APP_SERVER_URL=https://your-backend.onrender.com
```

## Common Issues

### CORS Errors
- Verify `CLIENT_URL` matches Vercel URL exactly
- No trailing slashes
- Redeploy backend after changes

### WebSocket Connection Fails
- Check backend is running (`/health` endpoint)
- Verify `REACT_APP_SERVER_URL` is correct
- Check browser console for errors

### Cold Starts (Free Tier)
- First request may take 30-60 seconds
- Expected behavior on Render free tier
- Upgrade to paid tier for always-on service

## Success Criteria

✅ Backend health check returns 200 OK
✅ Frontend loads without errors
✅ WebSocket connection established
✅ Room creation works
✅ Multiplayer synchronization works
✅ Bot players function correctly
✅ No errors in production logs
